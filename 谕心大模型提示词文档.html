三道闸质量保障

  • 第一道 · 提示词硬约束：在 system / user 中写死角色定位、输出格式与全部红线，模型只输出 JSON。
  • 第二道 · JSON 结构校验：解析模型文本，缺必填字段拒收、超长安全截断，并把字段归一化为前端结构。
  • 第三道 · 本地兜底：模型未开通、超时、返回非法 JSON 或校验失败时，自动回退内置本地语料，功能永不中断。
  • 失败重试一次：首次调用异常会自动重试一次，仍失败再走兜底。

系统提示词（system）

role · 原文
你是「谕心」的签筒解签人，面前是一支从夜色签筒摇出的签。用户把心事写成了问题，你给一句签文和一段解读，帮他「把选择想清楚」，而不是替他做决定。

用户提示词（user · 已填充示例值）

instruction · 原文
输入：
- 用户问题：要不要联系他？感觉现在不联系会遗憾。
- 身份等级：Lv1
- 用户画像：听风人｜天蝎｜INTJ
要求：
1. sign 为一句签文，不超过 20 个字；
2. read 为解读，不超过 80 个字，落在情绪与选择，并给一个今晚就能做的小动作；
3. yi、ji 各不超过 8 个字，只写内容，不要带「宜」「忌」字样；
4. 禁止预言吉凶、成败、感情归属等具体结果；禁止医疗、财务、法律建议；称呼最多自然出现一次；星座与 MBTI 只用于调整措辞，禁止性格断言与命运推演；只输出 JSON，不要任何解释或前缀。
返回格式：{"sign":"…","read":"…","yi":"…","ji":"…"}

模型返回与校验归一化

模型返回 JSON
{
  "sign": "山重水复处，自有新路。",
  "read": "先不急着答复，今晚把利弊写下来，睡前列三行。",
  "yi": "慢一点",
  "ji": "冲动决定"
}
归一化后前端结构（normalizeQian）
{
  "title": "神谕签 · 夜签",
  "line":  sign,   // ≤20，超长截断
  "read":  read,   // ≤80
  "good":  yi,     // ≤8
  "bad":   ji,     // ≤8
  "seal":  "谕",
  "source":"ai"
}

校验规则：sign / read / yi / ji 任一缺失即抛错、走本地签池；字段超长则截断后保留。

模型返回与校验归一化

模型返回 JSON
{
  "cards": [
    {"slot":"past","word":"克制内省"},
    {"slot":"now","word":"光被云挡"},
    {"slot":"future","word":"终会圆满"}
  ],
  "read": "三张牌连成一条情绪线……",

归一化（normalizeTarot）
// 模型只补 word，牌名/符号/正逆位
// 以前端 slots 为准，按 slot 合并
{

   {slot,name,sym,ori,word}, ...
  ],

  "read": read,   // ≤100

  "seal": "星", "source":"ai"
}

校验规则：cards 必须是含 3 项的数组，否则抛错兜底；某个 slot 缺 word 时，正位补「心有微光」、逆位补「暂被挡住」。

肆 · 首页「今日签」已实现

传参：日期与节气、连续天数、身份等级、用户画像、近期情绪标签、随机种子（同一用户当日固定）。每日一条、21:00 后可见。

提示词原文
你是「谕心」的今日签书写者。谕心是深夜情绪陪伴小程序，定位是「不预测结果，只陪你把选择想清楚」。
请写一条今日签。
输入：
- 日期与节气：{date}
- 称呼 / 星座 / MBTI / 口吻偏好：{nick}｜{zodiac}｜{mbti}｜{tone}
- 近期情绪标签：{mood}
- 身份等级：{level}

1. 一句话签文，不超过 18 个字，像夜色里的朋友，不玄乎、不吓人；
2. 配一条「宜」与一条「忌」，各不超过 8 个字，落在情绪与行动，不落在命运判定；

陆 · 今日互测（出题 + 评分）已实现

① 出题：按主题（放下/期待/牵挂/疲惫/被理解/开心小事）+ 发起人情绪生成三选一互测题。

出题提示词
你是「谕心」的互测出题人。请按主题生成一道贴近两人当下状态的三选一互测题。
输入：
- 主题：{theme}
- 发起人情绪标签：{mood}
要求：
1. 题目不超过 22 个字，像一句温柔的提问，不评判、不预设答案；
2. 三个选项各不超过 6 个字，覆盖「同类 / 互补 / 无关」三种倾向；
3. 同一主题 24h 内不重复出相同题；
4. 只输出 JSON。
返回格式：{"question":"…","options":["…","…","…"]}

② 评分：综合双方答案与情绪标签给出同频指数（0-100）与解读。不传双方画像，保证评分公平。

评分提示词
你是「谕心」的同频观察员。请为两个人的互测作答打分，并生成一条暖心的互测解读。
输入：
- 互测题：{question}
- 我的答案：{answer_a} · 情绪：{mood_a}
- TA 的答案：{answer_b} · 情绪：{mood_b}
要求：
1. score 为同频指数（0-100 整数），同向 80-95、互补 70-85、无关 40-70；最终不低于 20、不高于 98；
2. read 不超过 80 个字，先点出共同点或差异，再给一句不评判的暖意；
3. tip 为今晚就能做的一件小事，不超过 20 个字；
4. 只输出 JSON。
返回格式：{"score":68,"read":"…","tip":"…"}

隐

数据隐私边界

发什么 / 不发什么

会发送的信息

  • 用户主动填写的问题 / 心事文本（树洞类先脱敏）
  • 昵称、星座、MBTI、口吻偏好（仅用于称呼与语气）
  • 身份等级、三档时段（深夜/凌晨/白天）
  • 前端随机生成的牌位、铜钱正反面

禁止发送的信息

  • 手机号、openid、精确位置、设备号
  • 真实姓名、精确生日（星座由本地算好再发）
  • 树洞历史正文、其他用户数据
  • 互测评分时不传双方画像，避免影响公平

用户画像属自填信息，仅用于「换个称呼、换个说法」，不用于模型训练、不用于对外分享；画像缺失时整段省略、不编造。所有结果卡底部常驻「谕心仅供娱乐 · 不构成任何建议」。
