YUXIN · ASK-RITUAL RESULT SCREEN

问事三式结果态：把"上满下空"改成"一屏三区"

抽签、翻牌、铜钱三张截图暴露的是同一个结构问题，不是三处独立瑕疵。下面先诊断，再给每式两套排版（A 沉浸式 / B 笺纸式），末尾附可直接使用的设计提示词。

一 · 诊断：六个问题，三式共有

01重心塌在上半屏：结果卡底边到按钮之间空出约 200–330px，屏幕下半没有任何信息，人眼会以为"下面是空的"。
02结果态还留着输入框：问题已问完，输入框仍占着最贵的第一屏位置，同时把结果往下挤。
03主视觉与结果卡断开：抽签态一根窄签条悬在中央，下面是独立纸卡，两者之间没有承接；翻牌态三张牌高矮不一、字距松散。
04印章压字：右上红色小印尺寸偏大且与"掷钱 · 今日""塔罗三张"几乎贴住，卡头一行被挤成两截。
05三按钮等权：收藏／生成卡片／再求一次三等分，"生成卡片"这个增长入口没有主次优势。
06层级扁平：标题、次数、卡头、签题、解读、宜忌字号差不足，第一视觉不明确，截图缩略时几乎糊成一片。

二 · 方案 A：沉浸式（主视觉占位、卡片承接、主按钮满宽）

分区高度：状态栏 30｜头行 44｜引文 40｜主视觉 弹性（约 190）｜结果卡 自适应｜主按钮 40 + 次按钮 32｜合规 16｜tabbar 46。死白被主视觉光晕与前后的承接关系填满，而不是靠加内容。

四 · 两方案怎么选

维度A · 沉浸式B · 笺纸式
第一眼主体在场：签条／牌／铜钱是视觉中心，仪式感靠"物"字在场：一张笺纸铺满，气质靠结构与排印
动效空间大：落定、光晕呼吸、牌面微颤、铜钱错落小：只有细线生长与字块淡入
与分享卡关系两套语汇（页面偏器物、卡片偏题跋），需统一同源：页面即卡片的放大版，品牌一致性最好
实现成本中：需处理三张牌错位与 canvas 光晕低：纯文字与细线，rpx 可控
适合要"惊艳、可截图传播"要"安静、耐看、贵"

五 · 优化后的提示词

你原来的说法是"更合理、更吸引眼球、更美观"——这三个词无法验收。下面把它改写成有诊断、有约束、有验收的版本，可直接交给设计或开发执行。

PROMPT · 问事三式结果态重设计
【角色与范围】
你是负责「谕心」小程序的 UI 设计工程师。本轮只重做「问事」页的结果态界面（抽签 / 翻牌 / 铜钱三式），不改产品逻辑、不改文案内容、不改五 tab 结构。视觉语言必须与既有品牌同源：深靛夜色底、素笺暖纸、鎏金描边、朱砂小印、宋体标题。

【已确认的现状问题（不要重新调研，直接修）】
1. 结果卡底边到按钮之间空白 200–330px，屏幕下半无信息，重心塌在上半屏。
2. 结果态仍显示输入框，占用第一屏且把结果下压。
3. 主视觉与结果卡之间无承接：抽签是一根 50px 窄签条孤立悬空；翻牌三张高矮不齐、字距松散。
4. 右上红印章尺寸偏大，与"掷钱 · 今日""塔罗三张"贴得太近，卡头被挤断。
5. 三个按钮等分，主次不分，"生成卡片"没有优势。
6. 字号层级扁平：标题、卡头、签题、解读、宜忌差异不足，缩略后糊成一片。

【设计目标（可验收，不是形容词）】
- 三层结构：问题引文（可折叠一行）→ 主视觉（弹性格，约 190–220px）→ 结果纸卡（承接主视觉，间距 ≤12px）。
- 结果态不得出现输入框；问题收拢成一行斜体宋体引文，右侧一个"改"。
- 单页无效留白 ≤80px（光晕、星尘、细线算有效）。
- 主按钮满宽 40px；次按钮并排两个 32px 描边；按钮区与合规语合计 ≤90px。
- 印章 ≤20px，固定在卡片右上外沿，不得压任何文字。
- 每式风格同源：同一套色值、同一套圆角（卡片 12px、按钮 10px、印章 2px）、同一套字号阶梯（20/17/13/11.5/9.5）。

【版式要求】
- 屏基准 306×640，等比换算 750rpx（系数 2.4509）；字号取整到 0.5rpx。
- 字号阶梯：页面标题 20、签题 17（长句 15.5）、解读 11.2、卡头 9.5、合规 8.5。
- 抽签：签条加宽到 78px、高占比 ≥62%，竖排两列（签题 + 侧批），下沿加签筒口沿阴影与地面弧光。
- 翻牌：三张统一 74×150，扇形 −7°/0/+7°，叠距 14px，中间一张抬起 8px；牌名、牌位、正逆三行左对齐。
- 铜钱：三枚 52px 横排，间距 13px，中间一枚抬起 9px，底部一道弧光。
- 结果卡内部顺序：卡头（式名 + 细线 + 今日）→ 签题大字 → 解读 → 细分隔线 → 宜忌双列。
- 翻牌态的"太阳·正位 → 隐士·正位 → 命运之轮·正位"改为三列小栏（牌名／位置各一行），不要一行长句。

【输出】
每式给两套方案：A 沉浸式（主视觉 + 光晕 + 承接卡）、B 笺纸式（整页一张笺纸，字当图，右下落款）。
每套必须说明：分区高度占比、元素清单、字号与色彩用法、入退场动效（入场 320ms 缓出，落定 480ms 回弹，禁止全局匀速）。

【约束】
- 不改文案、不改色值、不加组件库、不用 emoji 与图标字体，图标用内联 SVG 线稿。
- 所有按钮必须有真实反馈（跳转、toast 或状态变化），禁止僵尸按钮。
- 合规语「谕心仅供娱乐 · 不构成任何建议」必须在按钮下方原样出现。
- 宜忌不要做成两行红绿粗体：必须"小标签 + 单行内容"，颜色只用于内容字。

【验收清单（逐条打勾）】
1. 结果态无输入框；2. 卡片与主视觉间距 ≤12px；3. 单页无效留白 ≤80px；4. 主按钮满宽且高于次按钮；5. 印章 ≤20px 不压字；6. 三式字号与色值完全同源；7. 截图缩到 306px 宽仍能一眼分清签题与解读。
